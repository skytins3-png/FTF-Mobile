FTF 영화 프로젝트 곡 관리 - 모바일 PWA 버전

핵심 기능
- 영화 제목을 입력하면 영화 제목별로 자동 묶음
- 같은 영화 안에서는 FTF-01, FTF-02... 자동 번호
- ▲▼로 순서를 바꾸면 번호 자동 재정렬
- 모바일 화면 최적화
- 제목 복사 / 검색 / 수정 / 삭제
- JSON 백업 및 복구
- PWA 설치 지원

모바일 설치
1) GitHub Pages 같은 HTTPS 웹주소에 이 폴더의 파일을 모두 업로드
2) Galaxy Chrome 또는 Samsung Internet에서 주소 열기
3) '앱 설치' 또는 브라우저 메뉴 > 홈 화면에 추가
4) 설치 후 전체화면 앱처럼 실행 가능
5) 한 번 열어둔 뒤에는 오프라인에서도 기본 실행 가능

주의
- index.html을 휴대폰 파일에서 직접 여는 방식은 기본 사용은 가능하지만,
  진짜 PWA 설치/오프라인 캐시는 HTTPS 또는 localhost가 필요합니다.
